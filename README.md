# 📊 Sorting Algorithm Comparator GUI

An interactive **Sorting Algorithm Comparator** built using **Python, Tkinter, and Matplotlib**. The application allows users to run, visualize, and compare different sorting algorithms based on execution time, comparisons, swaps, and time complexity.

## ✨ Features

* 🔢 Supports Bubble, Insertion, Selection, Merge, and Quick Sort
* ⏱️ Measures algorithm execution time
* 🔍 Counts comparisons and swaps
* 📈 Displays execution-time graphs
* 🎬 Provides step-by-step sorting visualization
* ⚔️ Compares two algorithms side-by-side
* 🧠 Detects sorted, reverse-sorted, and random input
* 💡 Suggests a suitable algorithm based on input
* 📊 Displays Best, Average, and Worst-case complexity

## 🧮 Algorithms Implemented

| Algorithm      | Best Case  | Average Case | Worst Case |
| -------------- | ---------- | ------------ | ---------- |
| Bubble Sort    | O(n)       | O(n²)        | O(n²)      |
| Insertion Sort | O(n)       | O(n²)        | O(n²)      |
| Selection Sort | O(n²)      | O(n²)        | O(n²)      |
| Merge Sort     | O(n log n) | O(n log n)   | O(n log n) |
| Quick Sort     | O(n log n) | O(n log n)   | O(n²)      |

## ▶️ How to Run

### 1. Install Python

Make sure Python 3.x is installed.

```bash
python --version
```

### 2. Install Matplotlib

```bash
pip install matplotlib
```

### 3. Run the Application

```bash
python sorting_gui.py
```

## 🎮 How to Use

1. Enter comma-separated numbers or generate random numbers.
2. Click **Run** to execute all sorting algorithms.
3. View execution time, comparisons, swaps, and efficiency.
4. Select an algorithm under **Show Steps** to view its sorting process.
5. Select two algorithms under **Compare** to compare their performance.
6. View the graphical performance comparison and complexity table.
